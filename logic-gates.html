Logic gate networks

A normal neuron multiplies and adds hundreds of numbers. A logic gate neuron reads two bits and applies AND, OR, XOR or another two-input gate. The trick is to let the network learn which gate each neuron should be, and then throw the maths away: what's left is a circuit.

Train one yourself

Below is a tiny network looking at a 2×2 image (the four squares on the left). Every neuron starts as a random mix of all 16 gates. Press Train and watch each neuron commit to one gate. Then press Freeze: every neuron keeps its favourite gate, and the network becomes ordinary digital logic. Click the input squares to test it.

How it works

  1. Fix the wiring. Every neuron gets two inputs from the layer below, chosen at random once.
  2. Make gates differentiable. On real numbers in [0, 1], AND becomes \(a\cdot b\), OR becomes \(a+b-ab\), XOR becomes \(a+b-2ab\), and so on (table below). On 0s and 1s these give exactly the truth tables.
  3. Learn a mixture. Each neuron outputs a softmax-weighted average of its 16 relaxed gates. Gradient descent tunes the 16 weights per neuron.
  4. Freeze. Keep each neuron's most likely gate. The network is now a Boolean circuit with no multiplications at all.
  5. Run at logic speed. A CPU evaluates one gate on 64 inputs at once with a single bitwise instruction, and FPGAs and chips implement gates directly.

Why it's interesting

Inference costs almost nothing. In the original paper, logic gate networks classified more than a million MNIST images per second on a single CPU core (Petersen et al., NeurIPS 2022). The convolutional version scales to CIFAR-10 while using far fewer gates than earlier approaches (Petersen et al., NeurIPS 2024). The price is a harder training problem: the gates are discrete, so you need good relaxations, initialisations and wiring.

Where I'd use it

  • Medical implants and wearables. A closed-loop neurostimulator has to decide in microseconds, on a battery that must last for years. A logic circuit fits in that budget.
  • FPGAs and custom chips. A trained network maps one-to-one onto lookup tables, with no multipliers and no floating point.
  • Always-on sensing. Keyword spotting, anomaly detection and event cameras: cheap enough to run all the time, on the device, keeping data private.
My implementation: silogic is a compact, hackable PyTorch library for differentiable logic-gate networks: fully connected and convolutional logic layers, several gate parameterisations, n-input lookup-table nodes and fused Triton kernels. A trained model discretises into integer truth-table lookups that map directly onto FPGA/ASIC LUTs.
